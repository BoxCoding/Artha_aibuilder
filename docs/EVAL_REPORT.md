## Why these numbers are optimistic

These rates are measured on statements generated by `app/synthetic/generator.py` and read by a parser written against that same layout, so near-perfect scores are expected and should be discounted accordingly. What the suite genuinely demonstrates is that the detection logic is wired to ground truth, that no severe finding can be approved around, and that regressions surface as gate failures. Specifically:

- **Extraction** is tested on one clean, text-layer layout. Real statements arrive as scans, photographs and a long tail of bank templates; the Gemini extraction path that handles those is not covered by these numbers at all.
- **Tampering patterns** are the four this generator produces. A real forger has many more options, including re-typesetting the whole document, which would defeat both the font and the metadata checks.
- **Injection strings** are drawn from the same pattern family the detector was written against. Measuring real resistance needs an adversarial set the detector has not seen.
- **Groundedness** is measured on the offline composer, which constructs citations by construction. The figure worth tracking is the same rate for Gemini-authored memos, where the groundedness gate is load bearing rather than decorative.

The honest next step before any pilot is a held-out set of real, consented statements with human-labelled tampering, and an adversarial injection set written by someone other than the author of the detector.

## Interpretation

- Integrity findings refer cases to a human; they never decline anyone automatically.
- Every memo claim carries a citation that resolves to a stored evidence record; unciteable claims are removed by the groundedness gate before an underwriter sees them.
- Injection strings are redacted at ingest, so the text never reaches a model, and are reported as a finding rather than silently dropped.
